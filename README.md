# BeerTracker

Aplicação para registar as cervejas que vai bebendo e ver estatísticas sobre elas. Esta é a versão web de testes (HTML, CSS e JavaScript).

## Como correr

Com Node.js instalado:

```
npm start
```

e abrir http://localhost:8000. Em alternativa, abrir o ficheiro `index.html` diretamente no browser.

## Testes

```
npm test
```

## Trabalhar com o Claude Code

Abrir um terminal nesta pasta e correr `claude`. O ficheiro `CLAUDE.md` dá-lhe o contexto do projeto.
